# Multi-page redesign Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn the single scrolling evidence page into a seven-page site in theme C (white, deep green, banner on every page) with diagrams, photo slots, a dated Highlights list and a Writing page.

**Architecture:** `build.py` stays the only generator. It gains a nav built from one group table, a sub-tab strip, an auto-built sidebar, and small helpers for cards, figures and case-study blocks. Content lists (`ARTICLES`, `HIGHLIGHTS`, `TALKS`, `PAPERS`, `IMAGES`) sit in `build.py` next to the pages that use them. `docs/assets/css/site.css` is rewritten. `tests/test_site.py` builds the site and enforces every rule in the spec.

**Tech Stack:** Python 3 standard library only (`unittest`, `re`, `html`, `pathlib`). Plain HTML, one CSS file, hand-written SVG. No JavaScript, no new dependencies.

**Spec:** `specs/2026-10-11-multipage-redesign-design.md`

## Global Constraints

Copied from the spec. Every task includes these.

- Every page carries the noindex robots meta tag. `robots.txt` disallows all.
- No awarding body name anywhere under `docs/` or in folder names, except inside the redirect stub directories `docs/bcs/` and `docs/iet/`.
- The `/bcs/*` and `/iet` URLs keep resolving, because the submitted form carries them.
- Writing rules: no em dashes, no en dashes, no semicolons, no inline comma list of three or more items, no conclusory or promotional adjectives. Every checkable claim carries a source line.
- Counters stay exactly 26 years, 26 venues, 4 committees, 2 publications. No review count anywhere.
- Connect row is ORCID, LinkedIn and email only. No phone number.
- No scanned certificates. Recognition links to public registers.
- `evidence/` is never tracked and never published.
- No personal or commercial data in public images. Photos are checked for minors and private details before publishing, and EXIF data is stripped.
- Colors: white background, deep green accent near `#2f6b4f`, pale green tints. Contrast meets WCAG AA.
- Fonts: Archivo for sans, Spectral for serif, from Google Fonts as today.
- Nothing is pushed until the owner has reviewed the local build and approved.
- `docs/` HTML is machine-written. Only `docs/assets/css/site.css` and `docs/assets/img/` are hand-maintained.

## Review Focus

Failure modes the spec implies but a straight reading of the tasks would not pin down. Each has a test or a manual check named in the owning task.

1. **A photo file added to `docs/assets/img/` with no alt text.** The build must stop with a message naming `IMAGES`, never publish an image without alt text. Pinned in Task 5.
2. **`ARTICLES` empty.** No Writing page, no nav item, no home card, no related link, and no dead `/writing/` href anywhere. Pinned in Task 5.
3. **A stale anchor or dead internal link after the home page loses its old sections** (`/#publications`, `/#standing`, `/#recognitions`). Pinned in Task 1 by a link and fragment checker, fixed in Tasks 4 and 6.
4. **A 375px phone.** Nav wraps, card grid becomes one column, sidebar drops below the content, no horizontal scroll. Manual check in Task 8.
5. **Dark mode and print.** The white-on-green banner must stay readable when the OS is dark, and a printed page must show link addresses. Manual check in Task 8.

def read(rel):
    return (DOCS / rel).read_text(encoding="utf-8")


def all_html():
    return sorted(DOCS.rglob("*.html"))


def is_stub(path):
    return 'http-equiv="refresh"' in path.read_text(encoding="utf-8")


def real_pages():
    return [p for p in all_html() if not is_stub(p)]


def visible_text(raw):
    raw = re.sub(r"<(head|style|script)\b.*?</\1>", " ", raw, flags=re.S)
    return html.unescape(re.sub(r"<[^>]+>", " ", raw))


def nav_items(raw):
    block = re.search(r'<nav class="site-nav".*?</nav>', raw, re.S).group(0)
    return re.findall(r'<a href="([^"]+)"( aria-current="page")?>([^<]+)</a>', block)


def expected_nav():
    items = list(NAV)
    if not (DOCS / "writing" / "index.html").exists():
        items = [i for i in items if i[0] != "/writing/"]
    return items


class Structure(unittest.TestCase):
    def test_topic_pages_are_real_pages(self):
        for rel in TOPIC_PAGES:
            with self.subTest(rel=rel):
                self.assertTrue((DOCS / rel).exists(), f"{rel} is missing")
                self.assertFalse(is_stub(DOCS / rel), f"{rel} is still a redirect stub")

    def test_redirect_stubs_keep_resolving(self):
        for rel, target in STUBS.items():
            with self.subTest(rel=rel):
                self.assertIn(f'url={target}"', read(rel))

    def test_every_page_is_noindex(self):
        for p in all_html():
            with self.subTest(page=p.relative_to(DOCS).as_posix()):
                self.assertIn("noindex", p.read_text(encoding="utf-8"))
        self.assertIn("Disallow: /", (DOCS / "robots.txt").read_text())

    def test_topic_pages_have_a_sidebar(self):
        for rel in TOPIC_PAGES:
            with self.subTest(rel=rel):
                raw = read(rel)
                self.assertIn('<aside class="side"', raw)
                self.assertIn("On this page", raw)


class Navigation(unittest.TestCase):
    def test_same_items_on_every_real_page(self):
        for p in real_pages():
            with self.subTest(page=p.relative_to(DOCS).as_posix()):
                items = [(h, l) for h, _, l in nav_items(p.read_text(encoding="utf-8"))]
                self.assertEqual(items, expected_nav())

    def test_current_item_matches_the_page(self):
        for rel, label in CURRENT.items():
            if not (DOCS / rel).exists() or is_stub(DOCS / rel):
                continue
            with self.subTest(rel=rel):
                current = [l for _, c, l in nav_items(read(rel)) if c]
                self.assertEqual(current, [label])

    def test_sibling_pages_share_a_tab_strip(self):
        for group in SIBLINGS:
            for rel in group:
                with self.subTest(rel=rel):
                    strip = re.search(r'<nav class="subtabs".*?</nav>',
                                      read(rel + "index.html"), re.S)
                    self.assertIsNotNone(strip, f"{rel} has no tab strip")
                    for other in group:
                        self.assertIn(f'href="/{other}"', strip.group(0))


class Rules(unittest.TestCase):
    def test_no_dashes_or_semicolons_in_prose(self):
        for p in real_pages():
            text = visible_text(p.read_text(encoding="utf-8"))
            for bad, name in (("\u2014", "em dash"), ("\u2013", "en dash"), (";", "semicolon")):
                with self.subTest(page=p.relative_to(DOCS).as_posix(), bad=name):
                    self.assertNotIn(bad, text)

    def test_no_awarding_body_names(self):
        pattern = re.compile(r"\b(bcs|iet)\b", re.I)
        for p in all_html():
            rel = p.relative_to(DOCS).as_posix()
            if rel.startswith(("bcs/", "iet/")):
                continue
            with self.subTest(page=rel):
                self.assertIsNone(pattern.search(p.read_text(encoding="utf-8")))

    def test_counters_agree_everywhere(self):
        got = dict(re.findall(r'data-counter="(\w+)">(\d+)<', read("index.html")))
        self.assertEqual(got, {"years": "26", "venues": "26",
                               "committees": "4", "publications": "2"})
        review = read("peer-review/index.html")
        self.assertEqual(review.count('class="venue-row"'), 26)
        self.assertEqual(review.count('class="committee-row"'), 4)
        self.assertEqual(read("publications/index.html").count('class="pub-entry"'), 2)

    def test_no_review_totals(self):
        pattern = re.compile(r"\d+\s+(papers|reviews)\s+(reviewed|completed)|reviews completed", re.I)
        for p in real_pages():
            with self.subTest(page=p.relative_to(DOCS).as_posix()):
                self.assertIsNone(pattern.search(visible_text(p.read_text(encoding="utf-8"))))

    def test_connect_row_is_orcid_linkedin_email_only(self):
        row = re.search(r'<div class="connect-row">(.*?)</div>', read("index.html"), re.S).group(1)
        hrefs = re.findall(r'href="([^"]+)"', row)
        self.assertEqual(len(hrefs), 3)
        self.assertTrue(hrefs[0].startswith("https://orcid.org/"))
        self.assertTrue(hrefs[1].startswith("https://www.linkedin.com/"))
        self.assertTrue(hrefs[2].startswith("mailto:"))

    def test_no_phone_links(self):
        for p in all_html():
            with self.subTest(page=p.relative_to(DOCS).as_posix()):
                self.assertNotIn("tel:", p.read_text(encoding="utf-8"))


IMG = re.compile(r"<img\b[^>]*>")


def attr(tag, name):
    m = re.search(rf'\b{name}="([^"]*)"', tag)
    return m.group(1) if m else None


class Images(unittest.TestCase):
    def test_every_image_exists_and_has_alt_text(self):
        for p in real_pages():
            rel = p.relative_to(DOCS).as_posix()
            for tag in IMG.findall(p.read_text(encoding="utf-8")):
                with self.subTest(page=rel, tag=tag):
                    src, alt = attr(tag, "src"), attr(tag, "alt")
                    self.assertIsNotNone(alt, "image has no alt attribute")
                    if src.startswith("/"):
                        self.assertTrue((DOCS / src.lstrip("/")).exists(), f"{src} is missing")
                    if alt == "":
                        self.assertTrue(src.startswith("/assets/img/card-"),
                                        "only decorative card art may have empty alt text")

    def test_alt_text_is_unique_per_image(self):
        seen = {}
        for p in real_pages():
            for tag in IMG.findall(p.read_text(encoding="utf-8")):
                src, alt = attr(tag, "src"), attr(tag, "alt")
                if not alt:
                    continue
                with self.subTest(alt=alt):
                    self.assertEqual(seen.setdefault(alt, src), src,
                                     "two different images share one alt text")


class Links(unittest.TestCase):
    def test_internal_links_and_anchors_resolve(self):
        for p in real_pages():
            rel = p.relative_to(DOCS).as_posix()
            raw = p.read_text(encoding="utf-8")
            for href in re.findall(r'href="([^"]+)"', raw):
                if href.startswith(("http", "mailto:", "//")):
                    continue
                with self.subTest(page=rel, href=href):
                    path, _, frag = href.partition("#")
                    if path == "":
                        target = raw
                    else:
                        f = DOCS / path.lstrip("/")
                        if f.is_dir():
                            f = f / "index.html"
                        self.assertTrue(f.exists(), f"{href} does not resolve")
                        target = f.read_text(encoding="utf-8", errors="ignore") if f.suffix == ".html" else ""
                    if frag:
                        self.assertIn(f'id="{frag}"', target, f"no anchor #{frag}")

```python
def page_key(path: str) -> str:
    return path[:-len("index.html")] if path.endswith("index.html") else path


def nav(key: str) -> str:
    out = []
    for label, landing, members in NAV_GROUPS:
        cur = ' aria-current="page"' if key in members else ""
        out.append(f'      <li><a href="/{landing}"{cur}>{label}</a></li>')
    return '<ul class="nav-list">\n' + "\n".join(out) + "\n    </ul>"


def subtabs(key: str) -> str:
    """A tab strip under the header for pages that share a nav item with a sibling."""
    for _, _, members in NAV_GROUPS:
        if key in members and len(members) > 1:
            items = []
            for m in members:
                cur = ' aria-current="page"' if m == key else ""
                items.append(f'<li><a href="/{m}"{cur}>{PAGE_LABELS[m]}</a></li>')
            return ('<nav class="subtabs" aria-label="In this section"><div class="wrap">'
                    "<ul>" + "".join(items) + "</ul></div></nav>")
    return ""


def add_sidebar(key: str, body: str) -> str:
    """Give each h2 an id and add an 'On this page' and 'Related' sidebar to the wrap."""
    if '<div class="wrap">' not in body:
        return body
    heads, used = [], set()

    def tag(m):
        text = re.sub(r"<[^>]+>", "", m.group(1)).strip()
        base = re.sub(r"[^a-z0-9]+", "-", text.lower()).strip("-") or "section"
        slug, n = base, 2
        while slug in used:
            slug, n = f"{base}-{n}", n + 1
        used.add(slug)
        heads.append((slug, text))
        return f'<h2 id="{slug}">{m.group(1)}</h2>'

    body = re.sub(r"<h2>(.*?)</h2>", tag, body, flags=re.S)
    on_page = "".join(f'<li><a href="#{s}">{html.escape(t)}</a></li>' for s, t in heads)
    related = "".join(
        f'<li><a href="/{k}">{PAGE_LABELS[k]}</a></li>'
        for k in RELATED.get(key, []) if k != "writing/" or ARTICLES
    )
    aside = ('<aside class="side" aria-label="On this page">'
             f'<p class="side-h">On this page</p><ul>{on_page}</ul>'
             f'<p class="side-h">Related</p><ul>{related}</ul></aside>')
    body = body.replace('<div class="wrap">', '<div class="wrap topic">', 1)
    end = body.rfind("</div>")
    return body[:end] + aside + "\n" + body[end:]
```
