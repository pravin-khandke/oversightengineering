## Search engines

The site asks not to be indexed. `docs/robots.txt` carries `Disallow: /` and every page
carries `<meta name="robots" content="noindex, nofollow, noarchive, nosnippet">`. Both are
generated by `build.py`, so they survive every rebuild rather than living as files someone
can lose.

Reached from a search result is not how an assessor is meant to arrive. They arrive from the
link in the application form.

Two things this does not do. It does not remove anything a search engine has already
indexed, because a robots request is not retroactive. It also does not stop a link preview,
so pasting the address into a message still produces a title and description card, which is
usually what you want.

Reversing it is a one-line change to `build.py`.

## How to change the site

1. Edit `build.py`. The page content lives in the `add(...)` calls near the bottom, one per page.
2. Run it:

       cd ~/Documents/GitHub/oversightengineering
       python3 build.py

3. It rewrites `docs/`. Then commit and push:

       git add -A && git commit -m "content: describe the change" && git push

GitHub Pages redeploys on its own within a minute or two.

Do not hand-edit files in `docs/`. They are generated, and the next build overwrites them.
